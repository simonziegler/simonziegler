I run two companies: one builds software for commercial real-estate lenders, the other
builds the UI components underneath it. I've been a software engineer, investment banker
in derivatives trading (Deutsche Bank and Merrill Lynch), and a real-estate developer.

**[Chameleon UI by Materia Technologies](https://chameleonui.io)** is a library of Material 3
Expressive web components for Web/JS, React, Blazor, Angular, Vue and Svelte. One seed color,
or an image, generates a full theme. Corner shapes work in every browser (and that means
squircles!), and every component targets WCAG 2.2 AA. The Community tier gives you
15 components free for commercial use, and a [docs MCP server](https://chameleonui.io/get-started/ai-agents#the-mcp-server)
serves the docs to your AI coding tools.

Chameleon grew out of **[Dioptra](https://dioptra.tech)**, my loan-portfolio analytics platform.
Dioptra needed a serious UI, which led me to co-create
[Material.Blazor](https://material-blazor.com) and then Chameleon UI.
